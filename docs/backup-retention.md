# 远端备份保留策略

每个 S3、WebDAV、Drive 地点可独立设置保留份数：`0` 关闭（默认），`1..100` 保留最近成功上传的副本。新建备份及上传既有归档都参与计数，排序依据是应用记录的上传完成时间，不推断归档内邮件的新旧。既有归档重复上传也是一个新副本。

只有真正的超级管理员可以修改；启用必须明确确认不可撤销的远端清理。保存策略不会立即删除数据；下次该地点上传成功才检查历史。同地点的新配置代、不同地点及没有可信任务收据的远端文件都不会被纳入清理。

## 执行顺序与保护

1. 上传完成后，先把新对象名、可信 SHA-256 和字节数写入加密任务记录，任务进入 `retaining` 阶段，继续续租并响应取消。
2. 从本实例经过认证的成功/部分成功历史中选取同地点、同配置指纹的成功结果。保留当前新对象和最近的其他副本；当前对象永不作为清理候选。
3. **完整下载回读新密文**，验证 age 格式头、字节数及可信 SHA-256；失败时不删除任何旧副本。此步骤不持有恢复私钥，不构成 age 全流解密或数据库恢复验收。
4. 每次删除前重新检查启用状态、保留份数、地点配置、任务取消及当前租约。先持久化旧副本的 `pending` 删除意图，再完整回读旧密文校验收据；回读结束后再次检查当前授权，然后使用同一次读取的强 ETag 发出 `If-Match` 条件删除。
5. 远端确认删除后标记 `deleted`；请求、进程或数据库中断可能留下 `pending`，界面明确提示不能将其视为确定可恢复副本。后续新的成功备份可重新核对；远端返回 404 时记为 `missing`，不冒充本次确认删除，也不反复阻断后续候选。

不遍历云目录，不猜测对象归属，不删除目录/桶，不处理未确认的上传残留，不自动删除本地密文目录或任务历史。S3/WebDAV 对象名必须符合本应用命名及当前前缀；Drive 还校验父目录、地点和可信摘要属性。所有请求保留 HTTPS、DNS/IP 约束、无环境代理及拒绝重定向策略；不将凭据或远端响应正文写入报告。

缺少强 ETag、条件请求被拒绝、只返回异步接受、对象变化、凭据失效或网络失败时停止该地点清理；不退化为无条件删除。供应商必须正确实现条件请求，真实供应商尚未验收；不支持的服务可能一直保留超额副本。Drive API 若不返回所需强 ETag，同样只报告清理未完成。

## 并发、中断与限额

- 使用原有跨实例租约队列及 CAS，删除意图和租约在同一短事务内校验；网络传输不占用事务或业务 DB 连接。不会启动独立、无界的清理 worker。
- 清理最多十分钟，每次读回/删除最多五分钟，仍受父任务一小时时限和取消约束。每地点每轮最多确认删除 16 个对象；超额工作显示 `retention_more_pending`，下次成功上传继续。
- 扫描最多 10,000 条任务历史，超过上限或遇到损坏/不完整历史时停止清理并报告 `retention_history_unavailable`。任务历史和本地归档仍需操作者管理容量，不能把远端保留策略当作本地磁盘清理。
- 多地点互相隔离；失败地点没有本轮新成功副本，不执行该地点清理。成功地点可独立清理。清理错误和已删除数量记录于 `retention`，不会抹掉上传收据或将上传成功改成失败。
- 已发出的远端请求无法通过取消或配置修改撤回；配置修改约束后续操作。保留份数不是对云端被外部删除、存储故障或管理员改写对象的绝对可用性保证，仍需独立保管收据和演练恢复。
- 旧任务的原上传 `results` 保留审计意义；以 `pruned[destinationId]` 判断副本是否已清理或结果不确定。`pending`、`deleted`、`missing` 均不能算作确认可恢复副本。

## 管理 API

`GET /api/admin/backups/destinations` 每个地点新增 `keepLast`（旧记录为 `0`）。保存：

```text
POST /api/admin/backups/destinations/{id}/retention
{"revision":"<current-destinations-revision>","keepLast":7,"confirm":true}
```

停用时提交 `keepLast:0`，无需确认。陈旧 revision 返回 `409`，非法数量或缺少启用确认返回 `400`。配置沿用加密地点库，不新增表；修改保留份数不改变地点凭据指纹，不会使原每日计划或排队上传失效。普通地点编辑保留当前策略，删除地点配置不会发起远端删除。

任务详情/下载报告新增 `retention`（逐地点删除数量和安全错误码）及 `pruned`（历史副本状态、时间和发起任务 ID）。这些是管理员会话接口，不向开放 API Token 授权。
