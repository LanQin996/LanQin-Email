# 可安装主题包 v1

在 **系统管理 → 系统设置 → 外观 → 主题管理**，上传本地 `theme.tar.gz`，或粘贴公开 GitHub 仓库／Release 地址。安装后先用合成数据预览，再选择是否在用户前台、管理后台或两边启用。主题包只装一次，两侧可以使用不同的包或版本。

- 使用**仓库地址**可安装最新的正式 Release。使用 **Release 标签地址**或该 Release 的 `theme.tar.gz` **附件地址**可安装指定版本。请勿使用仓库源码压缩包，也不支持私有仓库。
- 安装不自动启用。同 ID 不会静默覆盖；GitHub 更新必须确认，且来自同一仓库。更新只替换已安装版本，不动正在使用的版本。回滚会交换当前安装版本与上一安装版本。打开预览确认后，再把目标版本应用到需要更新的区域。
- 刷新或重新打开前台／后台会采用新的组合；已打开的页面不会因为管理员改版本而重挂载，避免打断写信或设置编辑。
- 停用某侧主题包后，该侧恢复站点原来配置的布局和全站配色。删除前先停用两侧。若后台显示异常，打开 `/admin?section=settings&tab=appearance&layout=classic`，可临时用经典布局并忽略主题包；不写配置，也不绕开登录或权限。

## 制作并发布

复制 [Linen Desk 示例](examples/theme-package/theme.json)。给你的包选一个唯一的小写 ID 和新的语义化版本；`classic`、`workbench` 和 `paper` 为保留 ID。根目录文件名必须为 `theme.json`，没有额外目录。只列出支持的 `front` 或 `admin` 区域，至少一个。每一侧选择内置布局 `classic` 或 `workbench`，并填写 `light` 和 `dark` 对象（可留空）。未设置的颜色继承站点默认配色。

颜色字段沿用 [配色主题契约](themes.md#可依赖的界面接口)，仅接收列出的 HSL 通道和圆角。压缩包上限 1 MiB，**只包含**一份清单；v1 不接受脚本、CSS、HTML、图片、字体或其他文件，不修改邮件正文、发信模板、权限或 API。若确实需要新的 React 布局，走[源码模板接口](layouts.md#开发主题)，经过代码审查再构建。

在示例目录执行：

```sh
COPYFILE_DISABLE=1 tar --format=ustar -czf theme.tar.gz theme.json
```

在公开仓库创建正式 Release，并把生成的 `theme.tar.gz` 作为附件上传。发布后不能用相同版本号替换已安装版本；修改时请发布新版本。安装端从 GitHub 获取包，校验附件大小与 GitHub 提供的 SHA-256 摘要（若有）。不需要 GitHub Token，不在浏览器加载第三方资源，也不执行压缩包里的代码。只有读取设置权限可查看列表；安装、启用、更新、回滚和删除都需要设置修改权限。
